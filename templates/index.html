¿Qué archivo debo cargar?

El sistema lee tu archivo .cdr de CorelDRAW y toma el tamaño exacto de la página como medida de alto y ancho — no hace falta anotar cotas a mano.

Convierte el texto a curvas. Cada letra debe ser un objeto de curvas; así el conteo es exacto aunque las letras se toquen entre sí (la "i" y la "f" en cursiva, por ejemplo).

Si la hoja trae varios conceptos (por ejemplo letras y una bandera), se usan los conceptos cuyo nombre dice "Letras" y se avisa cuáles se dejaron fuera. Las partes del logo cuentan como letras.

¿No tienes el .cdr? Sube una imagen (JPG/PNG) o un PDF con las cotas de alto/ancho ya dibujadas junto al diseño — el sistema las lee automáticamente y cuenta las piezas por contorno. Es menos preciso que el .cdr (letras que se tocan pueden contarse como una sola) y no sirve para nesting ni cálculo de LED, que necesitan el contorno vectorial exacto.
