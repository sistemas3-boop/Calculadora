7  ·  Prioridad de Cálculo — Resumen Visual

1
Catálogo — alto dentro del rango conocido
Tiempo exacto del catálogo  ·  badge NORMAL  ·  extrapolado = false
2a
ENSAMBLE sin flange + ancho disponible (alto fuera de rango)
mins = (0.2545 + 0.01067 × ancho_cm) × 60  ·  badge AMARILLO  ·  extrapolado = true
2b
Regresión lineal — alto fuera de rango + regresión disponible
Extrapolación  ·  badge AMARILLO  ·  mins = max(a + b × height, 0.1)  ·  extrapolado = true
3
Aproximación más cercana del catálogo
Entrada con altura más próxima  ·  badge AMARILLO  ·  extrapolado = true
4
Sin catálogo · sin regresión · sin alto
JS: mins = 0, badge "0 min"  ·  Python: ValueError → fila con error al usuario
